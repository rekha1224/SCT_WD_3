📌 Description

A simple and interactive Quiz Game built using HTML, CSS, and JavaScript. Users can select answers to multiple-choice questions and view their final score at the end.

🚀 Features

Multiple-choice questions

Answer validation

Score calculation

Final score display

Clean and responsive UI

🛠️ Technologies Used

HTML

CSS

JavaScript (Vanilla JS)

▶️ How to Run

Open index.html in any modern web browser.
